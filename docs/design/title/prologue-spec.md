# プロローグ — 表紙と「あなたのこと」のあいだ

2026年9月10日
置き場所：`docs/design/title/prologue-spec.md`

表紙で「はじめる」を押したあと、プレイヤー設定（`あなたのこと`）の前に
短い独白を挟む。**なぜ全国の雀荘を歩くのか**を、遊ぶ前に一度だけ渡す。

---

## 1. 出す条件

**新規のときだけ。**`title.js` の `data-act="new"`（「はじめる」／
「最初からはじめる」）を押した直後に入り、終わったら `renderSetup()` へ進む。

| 経路 | プロローグ |
| --- | --- |
| 「はじめる」（セーブ無し） | **出す** |
| 「最初からはじめる」（セーブ有り） | **出す** |
| 「続きから」 | 出さない |
| 設定画面の「戻る」 | 出さない（表紙へ戻る） |

**セーブに「見たか」を記録しない。**記録すると
`blankState()` / `loadState()` / `onStart()` の三箇所に書く項目が増える
（引き継ぎ書 §5 の `mailRead` と同じ形）。**押した経路で決まるので、覚える必要が無い。**

**「最初からはじめる」でも出す。**二周目の人には毎回になるが、
**とばす釦が最初から出ている**ので一押しで抜けられる。
条件を分けると「二周目かどうか」を覚えることになり、上と矛盾する。

## 2. 本文（確定稿）

`src/prologue.js` に持つ。**一画面＝一つの配列、一行＝一つの文字列。**

```js
const PROLOGUE = [
  ['最後の牌を、河に置いた。',
   '勝った。',
   'グラスの氷が、ひとつ崩れた。',
   '窓の外は、六本木の夜だった。'],

  ['卓の四隅に、知らない顔は、ひとつも無かった。',
   'ヒールのまま、タクシーを拾って、',
   '行き先は、東京駅とだけ告げた。'],

  ['新幹線を降りて、在来線に乗り換えて、',
   'それでもまだ足りなくて、歩いた。',
   '潮の匂いのする港町の、看板の字が半分消えた店。',
   '雨の商店街の奥、シャッターの隙間から漏れる、牌を混ぜる音。',
   '灯りの数だけ、卓があった。'],

  ['卓の数だけ、まだ誰も知らない手があった。',
   '牌を切る指が、きれいだった。',
   '振り込んでも、眉ひとつ動かさない子。',
   'ツモった刹那にだけ、ほどける口もと。',
   'スマホを伏せて、誰も、見ていない。'],

  ['──それが、いちばん惜しかった。',
   '麻雀は、四人にしか見えない。',
   'だから、見せる人が要る。',
   '見つけて、口説いて、育てて、灯りの下に立たせる人が。',
   '帰りの切符は、もう、買っていなかった。'],

  ['頂に、八人がいる。',
   '人は「雀エイト」と呼ぶ。',
   'いつか、あの八つの灯りを、ひとつの看板の下に並べる。',
   'まずは、看板を出すところから。'],

  ['その雀荘に、まだ見ぬ雀ドルがいる。'],
];
```

### 書くときの決めごと

- **名前を出さない。**設定画面はこのあとなので、名前はまだ決まっていない。
  一人称は「私」で通す
- **人数を書かない。**題字と副題と同じ（引き継ぎ書 §7）。
  初期メンバーもキャラ総数も増減するので、書けば嘘になる。
  **「八人」だけは雀エイトの定義なので固定**
- **最後の一行は `Title.SUBTITLE` と同じ文。****副題を変えたらここも変える。**
  対にしてあるので、片方だけ動かさないこと
- **一画面は5行まで。**下の §6（高さ）の実測がこの前提で立っている
- **一行は句点か読点で切る。**折り返しに任せると、狭い画面で
  意味の切れ目と違うところで折れる

## 3. 操作

一画面ぶんの行を**上から順に浮かび上がらせる**。全部出たら次の画面へ進める。

| 操作 | 出ている途中 | 全部出たあと |
| --- | --- | --- |
| 画面を押す | **残りを即座に全部出す** | 次の画面へ |
| 「とばす」 | 設定画面へ | 設定画面へ |

- **途中で押したら飛ばすのではなく、その画面を全部出す。**
  読み終える前に次へ行ってしまうのがいちばん困る
- **最後の画面だけは押しても進まない。**釦（`はじめる`）を出して、
  それを押させる。**誤爆でプロローグが終わるのを、最後だけは防ぐ**
- **「とばす」は最初から出しておく。**あとから出すと、
  飛ばしたい人が飛ばせない時間ができる
- **戻る操作は付けない。**読み返したい人は「最初からはじめる」で通る。
  前の画面へ戻す道を作ると、行の再生状態を覚えることになる
- 進みぐあいは下に点で出す（画面数ぶん）

### 動きを減らす設定

`@media (prefers-reduced-motion: reduce)` のときは、
**押した時点で一画面ぶんを全部出す**（浮かび上がらせない）。
進みかたは変えない。

## 4. DOMの置きかた

**`.plRoot` は `position:fixed` の覆いにして、`#view` の外に置く。**
`document.body` に足し、閉じるときに `remove()` する（`.popup` と同じ形）。

```
body
 ├ #scroll
 │   ├ #coverWrap > canvas#cover   ← 触らない
 │   └ #view                        ← 表紙のDOMがそのまま残っている
 └ .plRoot                          ← これを被せる（z-index:60）
```

### 触ってはいけないもの

- **`#cover` のcanvas。**DOMから外さない・`display:none` にしない・
  中身を消さない（README「表紙とサムネイル」）。
  **上に覆いを重ねるだけなら、撮影には影響しない**
  ——`.popup` が既に全画面を覆っていて、サムネイルは撮れている
- **`fitTop()`。**表紙の縮めかたの実測（引き継ぎ書 §5「表紙は画面の高さに収める」）に
  手を入れない。プロローグは別の層なので、そもそも関係しない
- **`body.onTitle`。**表紙にいる扱いのままにする（上下の枠が出ない）

### `title.js` 側

`screen` は `'top' | 'setup'` の二つのまま。**プロローグは画面の切り替えではなく、
`setup` へ行く途中に挟まる覆い**として扱う。

```js
} else if (act.dataset.act === 'new') {
  playPrologue(function () { screen = 'setup'; renderSetup(); toTop(); });
}
```

`playPrologue(done)` は、`PROLOGUE` が無ければ**何も出さずに即 `done()`**。

## 5. ファイル

| 追加 | 中身 |
| --- | --- |
| `src/prologue.js` | `PROLOGUE`（本文）と `Prologue.play(done)` |
| `src/prologue.css` | 覆いの見た目 |
| `build.py` | `CSS` に `prologue.css`、`JS` に `prologue.js` を足す |

- `JS` の並びは **`title.js` より前**。`title.js` は呼ぶときにしか触らないので
  順序は効かないが、依存を先に並べる慣わしに合わせる
- **末尾に `if (typeof module !== 'undefined') module.exports = ...` を書く**
  （テストから読むため。`build.py` は削らない）
- **`localStorage` にも `Sound` にも触らない。**プロローグは音を鳴らさない

### 単体ページでは出さない

`team.html` / `taikai.html` / `meikan.html` は `prologue.js` を読まない。
`title.js` は `typeof PROLOGUE === 'undefined'` を見て、
**無ければ黙って設定画面へ行く**（`office.js` / `geo.js` が無いときに
事務所の欄を出さないのと同じ形）。

## 6. 高さと書体

### 高さ

**いちばん狭いのは iOS の横持ち 334px**（引き継ぎ書 §5。`innerHeight` は
390 を返すが実際は 334）。この高さで**5行が入ること**を条件にする。

- 本文 `font-size: clamp(14px, 3.6vmin, 19px)` / `line-height: 1.9`
- 5行で最大 約180px。上下の余白・とばす釦・進みの点を足して 約290px
- **入りきらないときは `overflow-y:auto` で流す。**行数を減らす仕掛けは作らない
  ——表紙の `fitTop()` のような実測の仕掛けをもう一つ持ちたくない

### 書体

**`var(--mincho)` を使う。丸ゴ（`Maru`）を使わないこと。**
`maru.css` の二つの woff2 は**表紙と UI に出る字だけを切り出してある**
（`tools/make-font.py`）。プロローグの字はそこに入っていないので、
指定すると**入っている字だけ丸ゴ・残りは代替書体**という混ざりかたになる。

**本文のためにフォントを焼き直さないこと。**450字ぶんの漢字を足すと
woff2 が太り、表紙の描画が遅くなる（canvasは `document.fonts.load` の
完了を待っている）。

## 7. 見た目

- 背景は `#081010`（表紙の下端と同じ色）。**写真は敷かない**
  ——顔を出すと「誰の独白か」を探させてしまう
- 文字は `var(--ivory)`、最後の一行だけ金（`var(--kin)` の背景クリップ）で
  副題と揃える
- 行は下から 8px ぶん持ち上げながら 520ms で入れる。**行ごとに 260ms ずらす**
- 画面が替わるときは 180ms で消してから次を入れる

## 8. クラス名

**接頭辞は `pl`。**`plRoot` / `plText` / `plLine` / `plSkip` / `plDots` / `plGo`。

CSSのクラス名は全画面で一つの名前空間（引き継ぎ書 §5）。
**`line` `text` `dots` のような一般名を裸で使わないこと。**
足したら、コミット前に

```
grep -rn "\.plRoot\|\.plLine\|\.plText\|\.plSkip\|\.plDots\|\.plGo" src/*.css
```

で既存に無いことを確かめる。**単体ページでの確認では足りない**
——`prologue.css` を読まない画面とぶつかった場合、`index.html` でしか壊れない。

## 9. 錠（テストで固定すること）

`tools/test-prologue.js`（DOMに触らない側）

1. `PROLOGUE` が**空でない配列の配列**で、**どの画面も5行以下**
2. **最後の画面の最後の行が `Title.SUBTITLE` と一致する**（§2 の対）
3. 本文に**算用数字が無い**（人数を書かないの機械的な確認。「八人」は漢数字）

`tools/drive-prologue.js`（Playwright）

4. 「はじめる」→ とばす → **`あなたのこと` が出る**
5. 「はじめる」→ 画面数ぶん押す → **`あなたのこと` が出る**
6. **「続きから」ではプロローグが出ない**（進行済みのセーブを入れて確認）
7. 334px / 812px の両方で、**`.plSkip` が画面の中にいる**
8. プロローグを閉じたあと、**`#cover` が DOM にあり、`getContext('2d')` の
   中身が空でない**（撮影が生きていること）

## 10. やらないと決めたこと

- **canvasに描かない。**表紙の絵はサムネイル用で、そこに文字を足すと
  撮影される絵が変わる
- **読み返す入口を表紙に作らない。**表紙は高さが足りず、あらすじを
  落として凌いでいる（引き継ぎ書 §5）。釦を一つ足すと、その実測が動く
- **音を付けない。**`Sound.init()` は対局に入るときの初期化で、
  ここで呼ぶと入口が二つになる。iOS のマナーモードの断りも表紙には無い
- **各雀ドルの紹介をここに混ぜない。**裏話は名鑑（`story.js`）の持ち分
