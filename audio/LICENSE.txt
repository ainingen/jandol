効果音について

--------------------------------------------------------------------
出典
--------------------------------------------------------------------
**音源を差し替えたら、必ずこの欄を書き換えること。**

| ファイル | 出典 |
| --- | --- |
| discard1〜4.wav | ElevenLabs Text to Sound Effects で生成。Starter プラン、生成日 2026-09-04 |
| discard.wav | 自作（tools/make-sfx.py の合成） |
| draw / call / riichi / agari / deal / dora / ryuukyoku / tap .wav | 自作（tools/make-sfx.py の合成・仮） |

**discard1〜4 は生成音。**生成したままの WAV は `audio_raw/`（コミットしない）に置き、
切り出しと整形は `tools/prep-sfx.py` が回す。プロンプトと採否の理由は
`audio_raw/discard/README.txt` にある。

**discard.wav（単数）だけは合成のまま。**四本が一本も読めなかったときの
控えなので消さないこと（`src/sound.js` の逃げ道）。

他所のゲームや配布素材からは採っていない（docs/design/match/spec.md §2.1）。
残りの8つを差し替えるときも、そのサービス名と利用条件（商用可か、
帰属表示が要るか）をこの表に書くこと。書き換え忘れると
「自作」と書いてあるまま他人の音が入る。

--------------------------------------------------------------------
差し替えかた
--------------------------------------------------------------------
**同じファイル名で上書きするだけ。**src/sound.js は名前しか見ていない。

- 打牌は discard1.wav 〜 discard4.wav の四本（一番よく鳴るので鳴らし分ける）。
  **四本そろっていなくてよい。**読めたものだけで鳴る
- discard1〜4 が一本も無いときだけ discard.wav を使う
- 他の8つ（draw / call / riichi / agari / deal / dora / ryuukyoku / tap）は一本ずつ
- どの名前が何本読むかは src/sound.js の FILES にある

生成音を入れ直すときは `audio_raw/` に置いて `python3 tools/prep-sfx.py`
（切り出し・モノラル・フェード・A特性RMSで音量合わせまで通す）。
合成の8つを作り直すときは `python3 tools/make-sfx.py`
（**こちらは discard1〜4 を書かない。**回しても生成音は潰れない）。
どちらのあとも `node tools/check-sound.js` を回す。

--------------------------------------------------------------------
このリポジトリでの扱い
--------------------------------------------------------------------
合成の音（discard.wav と残り8つ）は自作なので、他の部分と同じ扱いで使ってよい。
生成音（discard1〜4）は上の表の条件に従う。
