効果音について

--------------------------------------------------------------------
出典
--------------------------------------------------------------------
**音源を差し替えたら、必ずこの欄を書き換えること。**
いま入っているものは全部、tools/make-sfx.py で合成した仮の音（自作）。
他所のゲームや配布素材からは採っていない（docs/design/match/spec.md §2.1）。

| ファイル | 出典 |
| --- | --- |
| discard1〜4.wav | 自作（tools/make-sfx.py の合成・仮） |
| discard.wav     | 自作（tools/make-sfx.py の合成・仮） |
| draw / call / riichi / agari / deal / dora / ryuukyoku / tap .wav | 自作（tools/make-sfx.py の合成・仮） |

生成した音（ElevenLabs など）に差し替えるときは、**そのサービス名と
利用条件（商用可か、帰属表示が要るか）をこの表に書くこと。**
実際に牌を録った音や CC0 の素材でも同じで、出典はここが正。
書き換え忘れると「自作」と書いてあるまま他人の音が入る。

--------------------------------------------------------------------
差し替えかた
--------------------------------------------------------------------
**同じファイル名で上書きするだけ。**src/sound.js は名前しか見ていない。

- 打牌は discard1.wav 〜 discard4.wav の四本（一番よく鳴るので鳴らし分ける）。
  **四本そろっていなくてよい。**読めたものだけで鳴る
- discard1〜4 が一本も無いときだけ discard.wav を使う。
  **消さないこと**——差し替えの途中で打牌が無音になる
- 他の8つ（draw / call / riichi / agari / deal / dora / ryuukyoku / tap）は一本ずつ
- どの名前が何本読むかは src/sound.js の FILES にある

差し替えたら node tools/check-sound.js を回す（何本読めたか、鳴らし分けが
効いているかを見る）。仮の音に戻したいときは python3 tools/make-sfx.py。
種を固定してあるので、回せば同じ音が出る。

--------------------------------------------------------------------
このリポジトリでの扱い
--------------------------------------------------------------------
いまの音は自作なので、他の部分と同じ扱いで使ってよい（帰属表示は不要）。
差し替えたら、その条件は上の表に従う。
