**鳴る音は12本とも生成音になった**（2026年9月4日）。生成したままの WAV は
`audio_raw/`（コミットしない）に置き、切り出しと整形は `tools/prep-sfx.py` が回す。
プロンプトと採否の理由は `audio_raw/discard/README.txt` と
`audio_raw/sfx/README.txt` にある。

**合成のまま残っているのは discard.wav（単数）だけ。**discard1〜4 が
一本も読めなかったときの控えなので消さないこと（`src/sound.js` の逃げ道）。
**他の8つには控えが無い**——一本しか持たない名前なので、落とす先が要らない。

他所のゲームや配布素材からは採っていない（docs/design/match/spec.md §2.1）。
差し替えるときは、そのサービス名と利用条件（商用可か、帰属表示が要るか）を
この表に書くこと。書き換え忘れると「自作」と書いてあるまま他人の音が入る。

--------------------------------------------------------------------
差し替えかた
--------------------------------------------------------------------
**同じファイル名で上書きするだけ。**src/sound.js は名前しか見ていない。

- 打牌は discard1.wav 〜 discard4.wav の四本（一番よく鳴るので鳴らし分ける）。
  **四本そろっていなくてよい。**読めたものだけで鳴る
- discard1〜4 が一本も無いときだけ discard.wav を使う
- 他の8つ（draw / call / riichi / agari / deal / dora / ryuukyoku / tap）は一本ずつ
- どの名前が何本読むかは src/sound.js の FILES にある

生成音を入れ直すときは `audio_raw/` に置いて `python3 tools/prep-sfx.py`
（切り出し・モノラル・フェード・A特性RMSで音量合わせまで通す）。
切り出す位置と音の大きさの目標は、あの道具の SOURCES に一行ずつ書いてある。
**`tools/make-sfx.py` は控えの discard.wav しか書かない**
（回しても生成音は潰れない。prep-sfx.py と名前が重なったらその場で止まる）。
どちらのあとも `node tools/check-sound.js` を回す。

生成音（鳴る12本）は上の表の条件に従う。
