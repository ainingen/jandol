`img/` の 001〜200 と p01〜p12 を **176×234** に焼き直したもの（212枚・約1.0MB）。

**手で置かない。**焼くのは

```
python3 tools/make-thumbs.py
```

**読むのは小さく出す場所だけ。**

| 出る場所 | 表示px | 読む先 |
| --- | --- | --- |
| 大会のカード（`taikai.js` の `faceOf`） | 78〜86 | `thumb/` |
| 対局の席プレート・カットイン・順位表（`match.js` の `thumbOf`） | 24〜119 | `thumb/` |
| **局の締めの立ち絵**（`ui.js` の `faceBig`） | **150×196** | **`img/`** |
| 名鑑・表紙 | 大きい | `img/` |

**一律に振らないこと。**`thumb/` は 176×234 なので、**DPR 3 なら 58px 幅までが素**。
それより大きく出す場所は `img/`（768×1024）のまま。

**配布ZIPに必ず含めること。**無いとカードの顔が全部シルエットになる
（画面は普通に動くので、目では気づけない）。`build.py` が毎回枚数を出す。

絵を足したら回し直すこと。回し忘れるとその子だけカードで影絵になる。
